Product Page UI Description (E-commerce – Personalized Digital Artwork)

This screen represents a mobile-optimized product detail page for a personalized digital product (artwork), designed with a clean, minimal, conversion-focused layout.

🔝 Top Section (Urgency + Pricing)

At the very top, there is a small red urgency banner with bold text:

“In demand. 2 people bought this in the last 24 hours.”

Below that:

The current price (€26.00) is displayed prominently in large, bold font.
The original price (€34.67) is shown next to it in a smaller font with a strikethrough, indicating a discount.
Underneath, a green label reads:
“25% off · Limited time sale”
A smaller grey line of text follows:
“VAT included (where applicable)”
🏷 Product Title + Metadata

Below pricing:

A long, descriptive product title in standard-weight font:
“Minimalist Watercolour Sketch of Your Home | Personalized Digital House Artwork. Custom Thoughtful Housewarming Gift | Handmade in 48 Hours”
The title is multi-line and dense with keywords for SEO.

Under the title:

Seller name: PerfettaCreations
A 5-star rating display using star icons (filled stars), indicating strong reviews.
⚙️ Customization Options Section

This section contains dropdowns and user inputs for customizing the product.

1. Rush Fee Dropdown
Label: “Rush Fee (12–24 Hours Digital Delivery)”
Dropdown field with a rounded rectangle border
Default selected value: “No”
Includes a downward arrow icon indicating expandability
2. Options Dropdown
Label: “Options”
Another dropdown with the same styling
Default value: “House Only”
3. Add Personalisation Toggle
A collapsible section titled:
“+ Add personalisation (optional)”
Styled as a clickable expandable row (accordion-style)
✍️ Personalisation Input Section

Once expanded, it shows:

Section title: “Personalization”
Instructional text in small font:
“Text?”
“Type ‘Yes’ that you agree and understand that this is a digital listing and no product is shipped unless requested and additionally paid for.”
A large multi-line text input box:
Rounded corners
Light border
Placeholder empty
Character counter displayed at bottom right: “0 / 1024”
🔢 Quantity Selector
Label: “Quantity”
Dropdown selector (not a stepper)
Default value: “1”
Same rounded style with dropdown arrow
🛒 Call-To-Action Button

At the bottom:

A large, full-width button
Dark background (deep purple/charcoal tone)
Rounded pill-shaped edges
Centered white text:
“Add to basket”
🎨 Design Style & UX Notes
Overall aesthetic: minimalist, clean, soft neutral tones
Heavy use of rounded corners on inputs and buttons
Clear visual hierarchy:
Price → Title → Options → CTA
Mobile-first spacing (stacked layout, generous padding)
Subtle use of color:
Red = urgency
Green = discount
Dark button = action focus
Focus on conversion + personalization workflow
🧠 Functional Intent

This UI is optimized for:

Selling digital, customizable products
Encouraging urgency (social proof + discount)
Collecting structured personalization input
Minimizing friction with simple dropdowns and clear CTA
