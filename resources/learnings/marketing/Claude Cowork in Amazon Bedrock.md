## What to keep
- Run Claude Cowork inference through Amazon Bedrock to keep model traffic and controls in AWS.
- Rollout model: desktop install + MDM-pushed managed config (model ID/profile/auth/policy).
- Enterprise controls to emphasize in planning: IAM/API keys, VPC endpoints, CloudTrail, OpenTelemetry/CloudWatch, and inference profile residency choices.
- Positioning angle: move AI from developer-only tooling to cross-functional knowledge work with existing AWS governance.
